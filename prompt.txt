INCREMENTAL DATA UPDATE
=======================

Create:

scripts/update_history.ps1

and a Python equivalent callable by the application.

This is extremely important.

Once the historical database exists, the application must NEVER redownload everything.

At startup:

1. inspect the latest local historical timestamp/month;
2. determine what historical data is missing;
3. download ONLY the missing/recent range;
4. intentionally overlap a small recent period for robustness;
5. deduplicate timestamps;
6. replace/update only recent affected partitions;
7. leave old validated history untouched.

A reasonable approach is to redownload the current month and optionally the previous month, then deduplicate.

Do not download 2003-present on every application startup.
